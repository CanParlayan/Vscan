# Vscan

A web-application vulnerability scanning prototype combining a **Python scanner** with a **Next.js/React interface**.

The repository contains both components. The Python CLI can be run separately from the web UI; the UI/server code has additional configuration and service requirements.

## Scanner capabilities

The Python entry point (`main.py`) provides a crawler and modules for:

- Common-port enumeration
- HTTP security-header checks
- XSS and SQL-injection testing
- Outdated component checks
- TLS/cryptography-related checks
- JSON and PDF reporting

These are automated checks, **not a substitute for manual security testing**. Findings require validation.

## Python scanner: quick start

Use Python 3 in a virtual environment:

```bash
git clone https://github.com/CanParlayan/Vscan.git
cd Vscan
python -m venv .venv
python -m pip install -r requirements.txt
python main.py --url https://example.com
```

On Windows, you can activate the environment with `.venv\Scripts\activate` before installing dependencies.

Useful options:

```bash
python main.py --help
python main.py --url https://example.com --depth 2
python main.py --url https://example.com --scan-type headers
python main.py --url https://example.com --scan-type headers,outdated
```

The CLI supports `--quiet`, `--depth`, `--url`, `--xsspayload`, `--nohttps`, `--sqlipayload`, and `--scan-type`. Reports and log files may be generated by scanning.

## Web interface

The `app/` directory contains the Next.js frontend. To run its development server:

```bash
npm install
npm run dev
```

The repository also includes `server.js` for an Express-based integration and MySQL-related code. Running the Next.js development server alone does **not** imply that every backend or scanning feature is configured.

## Responsible use and data handling

Only scan systems you own or are explicitly authorized to test. Scans can create traffic and trigger alerts. Logs, scan reports, authentication details, and target-specific findings may be sensitive: keep them out of public commits and rotate any accidentally exposed credentials.
